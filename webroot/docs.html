RUM SDK Documentation

The VelocityCDN Real User Monitoring (RUM) SDK collects performance telemetry from your end users and streams it to the nearest edge node in real time. This guide covers the web snippet, the native agent, and all configuration options.

Web SDK Installation

Add the following snippet to the <head> of every page you want to monitor:

<script src="https://sdk.velocitycdn.io/rum.min.js"
        data-endpoint="/v1/metrics"
        data-site-id="YOUR_SITE_ID"></script>

Replace YOUR_SITE_ID with the site ID found in your VelocityCDN dashboard. The SDK is <4 KB gzipped and loads asynchronously.

Native Agent

For server-side and endpoint monitoring, install the native agent. It maintains a persistent QUIC connection to the assigned edge node, delivering sub-second metric streams with minimal CPU overhead.

# Linux / macOS
./velocitycdn-agent -server <edge-node>:443 -site-id YOUR_SITE_ID

# Windows
velocitycdn-agent.exe -server <edge-node>:443 -site-id YOUR_SITE_ID
The native agent uses HTTP/3 over UDP/443 for all communication. Ensure UDP/443 outbound is permitted in your firewall policy. The agent does not require inbound ports.

Endpoint Configuration

All telemetry is delivered to the /v1/metrics path on your assigned edge node. This path is fixed and cannot be changed in the Starter plan. Pro and Enterprise customers can configure a custom path via the dashboard.

Configuration Options

OptionTypeDefaultDescription
-serverstring—Edge node hostname and port (required)
-site-idstring—Your VelocityCDN site identifier (required)
-agent-pathstring/v1/metricsHTTP path for the metrics endpoint
-ignorecertboolfalseSkip TLS verification (use only with self-signed edge certs in dev)
-intervalint30Flush interval in seconds

TLS & Certificates

Edge nodes use TLS 1.3 with ECDSA certificates issued by Let's Encrypt. The native agent validates the certificate chain by default. In development environments using a private edge node with a self-signed certificate, pass -ignorecert to skip validation.

Metrics Path

The /v1/metrics endpoint accepts a long-lived HTTP/3 POST body. The agent opens the request on startup and streams length-prefixed binary frames for the lifetime of the process. The edge node closes the stream on graceful shutdown and the agent reconnects automatically.

Firewall rules should allow outbound UDP/443 to the edge node IP. The metrics stream will appear as standard HTTPS traffic to passive observers.

Protocol

The SDK uses HTTP/3 (QUIC over UDP/443) exclusively. Each agent instance opens a single multiplexed QUIC connection to the edge. Keepalive frames are exchanged every 30 seconds to maintain NAT bindings.

Troubleshooting

  • Agent exits immediately — verify UDP/443 outbound is not blocked.
  • TLS error — if using a dev edge node with a self-signed cert, add -ignorecert.
  • No data in dashboard — check -site-id matches the value in your dashboard.
  • High latency metrics — ensure the agent is pointed at the closest regional edge node.
