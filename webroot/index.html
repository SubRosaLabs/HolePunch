RUM SDK — field performance in minutes

Drop our 4 KB JavaScript snippet or install the native agent on your endpoints. It connects to the nearest VelocityCDN edge node and streams performance events in real time — no sampling, no data loss.

<!-- Web SDK -->
<script src="https://sdk.velocitycdn.io/rum.min.js"
        data-endpoint="/v1/metrics"
        data-site-id="YOUR_SITE_ID"></script>

The native agent for Linux, macOS, and Windows uses an always-on QUIC connection to the assigned edge node for minimal overhead and consistent sub-second metric delivery.
